ORB feature detector — OpenCV.js in the browser

ORB keypoints + 32-byte BRIEF descriptors via cv.ORB from OpenCV.js 4.3 (the opencv-wasm package, loaded from node_modules) — the reference OpenCV implementation. The JPEG is decoded by the browser's ImageDecoder (WebCodecs) — output is approximate vs orb_test.py because the browser decoder's pixels differ slightly from OpenCV's libjpeg-turbo decode.

Multi-image variant: descriptor similarity demo — loads several images and ranks their pairs by Hamming-distance matches.
